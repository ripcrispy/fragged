# Retro themes

Five nostalgic themes for **Settings › Preferences**. Each one evokes an era or a scene using original styling
only. There are no logos, product names, wallpapers, fonts or other trade dress from the things that inspired them.

| Theme | Scheme | Look |
| --- | --- | --- |
| **Millennium Desktop** | light | Early-2000s desktop: glossy blue title bars, cream window panels, a rounded green "go" button, sky backdrop |
| **Cartridge** | dark | Late-90s 3D console: charcoal plastic, chunky rounded shapes, pill buttons, a four-primary-colour stripe and box accents, low-poly background |
| **Arcade Blue** | dark | 16-bit attitude: deep cobalt, chrome navigation and buttons, speed lines, bold italic uppercase headlines |
| **LAN Party** | dark | 3 a.m. in a dark hall: CRT scanlines, phosphor green, neon cyan/magenta glow, terminal-style `>` headings |
| **Bulletin '06** | light | Mid-2000s gaming forum: brushed-metal banner, glossy navy headers, orange highlights, small dense text |

- **Permissions / settings / data:** none. Members using one of these fall back to the site default while the module
  is disabled.
- All five pass the project's WCAG 2.1 AA audit (contrast included) and respect `prefers-reduced-motion`.
- Everything is in `public/retro.css`. Each theme is a block of design tokens plus a few decorative rules, a
  good starting point for your own theme (see the [theme-pack README](../theme-pack/README.md)).
